# t1

| Folder | Content |
| --- | --- |
| [`board/`](board/README.md) | Main board of the OpenDAP T1: the SoC-based single board computer, its auxiliary MCUs and simulations |
| [`case/`](case/README.md) | The physical case of the OpenDAP T1: the core with its basic back cover, the device-side HAT case mechanics, and the mount that faceplates attach to |
| [`faceplates/cassette/`](faceplates/cassette/README.md) | Cassette faceplate, inspired by cassette Walkmans |
| [`faceplates/classic/`](faceplates/classic/README.md) | Classic faceplate, inspired by classic portable music players |
| [`faceplates/touch/`](faceplates/touch/README.md) | Touch faceplate, the default faceplate: touch display, status LED, microphone |
| [`product/`](product/README.md) | Product integration of the OpenDAP T1: product requirements, the complete assembly and system simulations, built from the exports of every component |

Each folder keeps its own `README.md`, `CLAUDE.md` and `REUSE.toml`; the licence texts are in `LICENSES/`. The folders came from the former `board`, `case`, `faceplate-cassette`, `faceplate-classic`, `faceplate-touch` and `t1` repositories with their history ([RFC 0017](https://github.com/opendap-project/rfcs/blob/main/text/0017-naming-and-topology.md)).
