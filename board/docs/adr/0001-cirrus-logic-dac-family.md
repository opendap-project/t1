# ADR 0001: Cirrus Logic DAC family

- **Status:** Accepted
- **Date:** 2026-10-21

## Context

The DAC must have a mainline Linux driver (BRD-001). ESS DACs have no mainline driver and their measured advantage is not meaningful for this product.

## Decision

Use a Cirrus Logic DAC (CS43198 class). The exact part is not fixed yet.
