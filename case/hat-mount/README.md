# HAT mount

Mechanics of the HAT's device-side piece: fixed to the core with screws, it carries the pogo-pin array and the flat cable from the board (hat-standard ADR 0001). Each HAT's own case lives in that HAT's repository.

Tool: [FreeCAD](https://www.freecad.org) 1.1. One folder per part with `<part>.FCStd` and `exports/`.
