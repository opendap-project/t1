# Simulations

Tools: Python 3 and [openEMS](https://openems.de) for electromagnetic simulation, plus Python libraries as each study needs.

## Layout

- `<study>/`: one folder per study.
  - `README.md`: the question the study answers and how to run it.
  - `pyproject.toml`: the study's Python dependencies.
  - `results/`: generated output, not committed.
