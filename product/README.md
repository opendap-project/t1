# T1

![OpenDAP T1 concept art: the T1 in graphite with its orange Action button and silver keys, playing "You Only Live Once" by The Strokes on Blackbird OS. Concept art, not a real device.](docs/concept-art/concept.png)

Product integration of the OpenDAP T1: product requirements, the complete assembly and system simulations, built from the exports of every component.

## Layout

- `components.yaml` — the component versions that make up a T1 configuration
- `assembly/`
- `renders/`
- `sim/`
- `docs/`
