# Documentation

| Folder | Contents |
|---|---|
| [`specs/`](specs/) | T1 specifications: interfaces between components, such as the [faceplate interface](specs/faceplate-interface.md), and the T1's own behaviour and values, such as [controls and the status LED](specs/controls-and-status-led.md) the [experience budgets](specs/experience-budgets.md), and the T1 [electronics integration and verification](specs/electronics-integration-verification.md) (its modules, interaction matrix and evaluation rows). Generic software specifications (audio profiles, devices and sync) are in [system](https://github.com/opendap-project/system/tree/main/docs/specs), and the interface mockups in [blackbird-ui](https://github.com/opendap-project/blackbird-ui/tree/main/renders/web) (RFC 0008). |
| [`adr/`](adr/) | Architecture Decision Records: decisions already taken. |
| [`requirements/`](requirements/) | Product requirements (PRD). Each requirement has an ID, a priority (**must** / **should**) and a status. |

Only information confirmed by the maintainers is recorded here. Earlier experiments are not a source.
